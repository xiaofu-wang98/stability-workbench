> **设计原则**：保留检测与 QC 运营人员既有的表格阅读和受控文件习惯，仅对导致系统解析脆弱、人工核对工作量暴增的 **5 处复合排版（T1~T5）** 做最小粒度拆分；所有历史旧表仍保留向后兼容解析，新项目与工作台回传统一推荐采用本套标准模板。

## 二、Top 5 最小改动规范（T1~T5）

1. **T1｜考察条件分格 + 告别 Wingdings2 `R` 勾选符号**
   - 将原表挤在单个合并格（如 `B3`）里的温度、相对湿度、放置方式、光照拆为 4 个独立字段格。
   - 统一使用纯文本或标准 Unicode 复选框 `☑ / □`，避免 Wingdings2 字体被程序读成字母 `R` 或双勾漏勾。
2. **T2｜显式拆分 `大类 | 检验项目 | 分析方法` 三列**
   - 「大类」列固定使用受控 **6 大类**（并内置下拉约束）：`1.鉴别`、`2.纯度和杂质`、`3.效价`、`4.含量`、`5.安全性`、`6.理化与其它`（`2.纯度和杂质` 下在系统内自动挂载二级细类标签：分子大小变异体 / 电荷变异体 / N糖谱 / 偶联与小分子杂质 / 工艺相关杂质）。
   - 修正现行 Word 模板中将颜色、澄清度、pH、渗透压、装量、水分误归入 `5.安全性` 的排版误差。
3. **T3｜显式拆分 `子检项/细项（含药典体系）` 与 `可接受标准` 两列**
   - 同一检项下包含多个子结果（如 SEC-HPLC 的单体/HMW/LMW，或 ChP/USP 双药典外观澄清度）时，逐行填明子检项与药典体系，彻底消除多行均只写「报告数据」导致无法区分的问题。
4. **T4｜纯时间点标签行 + 独立签署状态行**
   - 时间点行只写纯标签（`0M / 10D / 1M / 3M / 6M / 12M / 24M`）；计划日期（`EDATE` 公式）与签署进度（`已签报告 / 进行中 / 待检`）各占独立辅助行，不再拼接在时间点名称里。
5. **T5｜表尾结构化 3 列 AR/AE 异常小表**
   - 用 `时间点 | 对应检项 | AR/AE编号与说明` 替代自由长段表尾备注，彻底杜绝备注归属歧义及跨检项误拦截。

## 三、单位与双语书写规范（对齐 `SOP(G)-RQA-0-001`）

- 单位统一写法：`mg/mL`（非 `mg/ml`）、`μg/mL`、`EU/mL`、`EU/mg`、`mOsmol/kg`（非 `mOsm/kg`）、`cfu/10 mL`（非 `cfu/10ml`）、`%`（半角，非 `％`）、`粒/支`。
- 中英文实质核对红线：若某行中英文方法或子检项互相矛盾（如中文写“还原型”英文写 `NR CE-SDS`，或中文写“单体”英文写 `HMW`），系统将严格拦截交由人工确认，绝不自动猜测。
