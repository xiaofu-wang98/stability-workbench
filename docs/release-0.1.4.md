# 0.1.4 可比研究与真实报告接入

本版保留既有 V3 页面与台账交互，向所有真实项目开放可比性研究和报告中心。旧版的 IP166E 演示数组、预设工艺分组和报告示例不用于真实模式。

## 本轮实现

后端原有通用结果查询、Excel 和单图 PNG 已支持任意项目；原有 Word 模块仅为旧 CLI 输出，不构成网页报告中心。此前可比性页仍以 IP166E 演示样品和曲线为主，报告按钮仅提示消息。本版新增实际研究资源、成员角色、只读比较、Word 与完整报告包接口，没有通过解除隐藏来展示演示数据。

研究使用当前项目真实已提交样品。内部样品身份包括材料类别、批号、规格、用途，不只按批号合并。创建或调整研究必须先预览，再确认变更前、变更后、待分组、不参与的分配及依据。研究配置复用既有审计事件、revision、幂等与事务；同一样品可在不同研究中拥有不同角色，新样品默认待分组，不根据名称、产能或日期猜测工艺前后。

按本轮用户确认，可显式对齐本研究已选成员的规格及原稳定性研究编号，必须填写依据。对齐只改变本研究分表分图方式，不更新来源、正式键、身份关联或采用值。未确认的继续隔离；材料类别、用途、条件、方法与版本、单位、时间单位和报告体系继续分组。多份原研究数据仍保留独立曲线，不用同一时间点覆盖其他结果。

可比研究分放行和稳定性模式，先完整结果表、后图谱。放行支持两种表格方向及按需展开图；稳定性按需加载多图，每次最多3个请求。变更前虚线、变更后实线，使用真实时间坐标。表格并列展示值与采用值并支持来源查看；图点溯源到正式采用版本。缺失、待采用、ND、限值和文字不补零、不画普通数值点。无适用标准时不画标准线、不自动评价。

报告中心提供按批号与考察类型筛选的检测结果报告，以及按已保存研究选择放行、稳定性或两者的可比研究报告。每组图另有精确范围报告入口。可以单独下载 Word，也可下载包含 Word、Excel、PNG、范围快照、来源和哈希核验证据的 ZIP。Excel 保留原有双状态与原格来源；Word 表格反读与筛选事实逐项核对，PNG 元数据反读并校验范围。报告保留人工评价，不生成可比性、合格或有效期结论。

权限沿用既有规则：查看对所有可查看项目开放；研究配置保存允许既有技术员、负责人和管理员能力，纯只读 Actor 不可保存。报告生成与下载均由后端检查 export，当前角色配置为项目负责人或管理员。前端不能授予自身权限。

## 纵轴口径

页面和 PNG 使用同一个 `plot_axes.py`。默认概览范围由所有已选正式精确数值共同决定，隐藏图例不重新缩放。

| 检测类别 | 概览规则 |
| --- | --- |
| HMW、LMW、聚合体及杂质百分比 | 最小0～5%，超范围自动扩大，负值也保留 |
| 单体、纯度、主峰百分比 | 90～100%作为基础，低值或高值超出时自动扩大 |
| pH | 0～14作为基础，超范围数据继续保留 |
| 其他百分比，包括相对活性 | 从0到至少100%，高于100%的值扩大显示，不按100%裁切 |
| 其他量纲 | 保留数据范围，同时用数值量级的50%作为最小跨度，避免细微变化撑满图 |

这些只是显示尺度，不是接受限度。检测类别来自检项标签和单位，不包含项目号、表名或坐标业务白名单。未知检测项沿用通用量纲规则，可使用细节或手动范围。

细节模式明确提示微小波动被放大。手动范围须为有限数值、下限小于上限，且不能裁掉已选正式数值。导出使用已经成功绘制的范围，不使用尚未应用的输入。概览 PNG 不逐点标注数值，减少遮挡；细节 PNG 可显示数值。图谱始终使用原值，不平滑、不变换数值。

用户示例 ADCC0801 长期 HMW 的0.3%～0.6%已在副本验证为0～5%；手动0～2%的 PNG 与页面坐标一致。原文标准≤5.0%仍按原文保留，不因显示范围恰好相同而建立标准适用关系。

## 数据保护与验证

升级前备份位于 `outputs/backups/pre-014-20261105-01/`，包含 SQLite 一致性备份和两份冻结原件。本轮没有数据库迁移，不运行数据修复。开发和写入测试仅使用临时目录或 `outputs/comparability-014-acceptance/home/` 副本。

日常库与备份逐表比较时还原备份中的原件路径，所有业务行和两份原件哈希一致，证据见 `outputs/comparability-014-acceptance/daily-preservation.json`。实际使用时，明确保存研究会新增研究审计配置、幂等记录及项目修订；导出新增导出审计。二者都不修改已提交事实、原格或采用值。

验证包括：全量后端回归；真实 IP275 副本的 ADCC 坐标、裁切拒绝、手动 PNG 范围；研究预览与两批同图、虚实线和报告实际下载；切换 IP281 后清除上个项目结果且不出现 IP166E 样例；原台账只读全表、并发上限、单图故障重试和 Excel／PNG 下载；原页面桌面／移动基线及人工兜底编辑、合并拆分、保存和提交。合成回归另覆盖放行与稳定性隔离、幂等、修订冲突、研究对齐不改事实、导出权限与文件篡改拒绝。

真实示例报告已用 Microsoft Word 渲染并用 Poppler 转图，3页逐页检查；系统没有 LibreOffice，通用 `render_docx.py` 不能运行，因此使用已安装 Word 检查。Word 文本反读属于每次导出的自动校验；逐页视觉检查是本次发布验收，不声称每份用户报告都会自动视觉审查。

## 使用与故障定位

重新运行 `start.cmd` 后确认 `/health` 为0.1.4。所有真实项目显示可比研究与报告入口，也支持 `/?project=项目号&view=comparability` 或 `view=reports`。新研究为空时，先“新建研究”，预览并确认分组；系统不会从旧演示模板制造分组或要求重新入库。需要导出时以 `start.cmd --role project_lead` 或管理员角色启动。

| 现象或错误 | 应处理的位置 |
| --- | --- |
| 页面仍显示旧版／未开放 | 核对运行目录、`/health`，关闭旧服务后运行该目录 `start.cmd`；前端必须由 build.py 生成 |
| 没有研究或全部待分组 | 在研究配置中明确分组，不改结果库；配置接口为 comparison-studies |
| stale_revision | 刷新研究／台账后重试，后端 workflow_common 的修订检查不能绕过 |
| study_members／study_not_found | 核对当前项目与研究成员；排查 comparability.py 和研究选择请求 |
| chart_scope／chart_collision | 分开有冲突的检测身份或研究；排查 comparability.py、trend_export.py，不覆盖多条结果 |
| axis_clipped／axis_range | 扩大手动范围或修正上下限；规则在 plot_axes.py，接线在 research-reports.js、result-display.js |
| 报告403 | 使用具备 export 的角色；不要取消后端权限校验 |
| 报告生成／反读失败 | 页面显示具体错误；核查 study_reports.py、workflow_excel_verify.py 和导出目录 verification.json |
| 文件 export_changed | 已生成文件哈希变化，重新生成；不能直接改审计哈希绕过验证 |

新增 HTTP 接口以生成的 `contracts/v1/openapi.json` 为准。报告不是自动出具结论的评估系统；适用标准、研究方案接受限度及正式评价仍需要独立的业务确认。
