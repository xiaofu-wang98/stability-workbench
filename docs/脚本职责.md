# 脚本职责

## 日常与维护入口

| 路径 | 作用 |
|---|---|
| `start.cmd` | 日常唯一Windows启动入口，构建app.html并调用独立环境的start.py |
| `setup.cmd` | 首次安装独立环境和已锁定依赖 |
| `start.py` | 本地服务启动、独立数据目录、端口和角色选择 |
| `scripts/backup.py` | SQLite backup和原件SHA核对的独立备份，拒绝覆盖目标 |
| `scripts/generate_contracts.py` | 从实际模型生成Schema与OpenAPI |
| `scripts/accept_sources.py` | 冻结来源隔离回放，按任务语义选择，不按项目/表名白名单 |
| `scripts/benchmark_refresh.py` | 仅在outputs副本测量首次打开、完整读取与无变化刷新 |

## 测试与接口

tests/的每个test_*.py覆盖文件名所指的业务能力；test_manual_sheet.py集中覆盖人工兜底、权限、指纹、回滚、撤销、正常入库及Excel/PNG输出；旧功能回归保留以防精简破坏现有业务。tests/conftest.py仅生成合成来源和公共测试身份。测试不参与日常启动。

contracts/v1/*.json由模型生成；examples为契约测试的合成数据，不是示例业务库。app.html是当前唯一生成页面，不在其中直接修改源码。
