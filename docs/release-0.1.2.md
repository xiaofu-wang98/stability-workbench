- 沿用原台账：分区、批号、研究、条件、材料类别、规格及用途筛选，完整结果矩阵在图前。当前项目的选择在刷新后恢复。

## 故障定位

- 页面提示“后端尚未加载结果展示接口”：运行中的旧进程尚未重启，关闭旧服务并运行 `start.cmd`；无需修改数据库。若重启后仍404，检查 `api.py` 的两个路由、启动目录及 `build.py` 是否包含 `result-display.js`。
- 返回409或“身份/范围变化”：重新读取当前结果，检查 `result_display.py` 的严格分组、当前修订和查询选择；不能通过改数据库或模糊匹配绕过。
- 定性值、ND、限值或没有正式采用值：这是不画普通精确数值点的规则，矩阵保留原文；不是需要修库的错误。
- 图表库加载失败：检查 `frontend/v3/vendor/chart.umd.js` 和 `build.py` 的本地嵌入；矩阵仍可读取。
- 来源详情失败：检查 `v4-source-drawer.js`、来源接口、冻结原件路径及哈希；不自动补写来源。
- 导出被禁用/403：沿用既有角色权限；不将其解释为数据丢失。导出反读失败时报告 `workflow_excel_verify.py` 的具体错误，不提供伪成功下载。

应用启动仍为原 `start.cmd`，默认地址8772和日常data目录保持一致。新后端必须重启服务后加载，不需要重新上传或再次确认入库。
