# 稳研工作台交付物一：业务需求说明书 (MVP 最终规则与设计决定)

## 1. 概述与业务边界
本项目（稳研工作台 Stability Workbench）面向生物制品与化学药品的稳定性研究管理，覆盖从原始方案/标准/历史 Excel 录入、研究矩阵构建、结果录入与 COA 贯通、增量修改与作废留痕、直到受控综合报告导出的全流程单机化管理。

### 1.1 业务核心原则
- **事实不可篡改与完全溯源**：所有导入和录入的事实（原始文件、工作表、坐标、检测结果版本）一旦提交即生成永久版本，任何清空、更正、复测均通过新版本或作废审计记录体现，不可物理覆盖。
- **业务判断闭环**：系统只负责智能识别、预检拦截与冲突提示；最终业务裁决权归属研究员。系统保证“研究员在页面作出判断并保存后，能够顺利预检、入库、刷新与反读”，绝不允许“拦截之后无法修改或只能改数据库”。
- **单机独立与日常隔离**：验收与试用运行在独立的 `--home` 目录与指定端口下，不污染生产/日常 SQLite 数据库，不移动原始文件。

## 2. 核心业务规则与本轮设计决定

### 2.1 项目与样品身份管理
1. **样品联合唯一键**：
   - 样品不仅依靠批号（Batch）识别，而是由 `(项目规范编码, 材料阶段 DS/DP/Placebo, 批号, 规格, 包装/用途)` 构成联合唯一标识。
   - 参考品（Reference Substance）作为独立用途类型维护，防止被误套用 DS/DP 质控标准。
2. **项目别名与规范化**：
   - 项目支持别名映射（如 `501` 映射到 `IP501`），通过 `project_aliases` 表维护，不采用盲目的全局去前缀规则。
3. **沙盒隔离机制**：
   - 内置沙盒项目（显示名称为 `TEST`），通过 `workflow_projects.purpose = 'sandbox'` 进行底层控制。
   - 沙盒环境允许手工建表、COA 录入和 Excel 模板往返演练；严禁从“历史汇总表导入”流程向沙盒提交正式历史事实。

### 2.2 历史数据入库与自动建表
1. **确认即入库，关联不复制**：
   - 历史 Excel 确认入库在同一事务中完成事实版本生成、样品绑定及研究表映射。
   - 系统复用正式结果版本 ID，严禁为了“生成研究表”而重复拷贝一套孤立的结果版本。
2. **来源证据保留**：
   - 自动继承历史表中的检项名称（双语）、检测方法、时间点、开始日期、放置条件、设备与偏离事件（OOS/AR/AE）。
   - 原件中无明确证据的字段（如缺失开始日期或特定批次规格）保持“待补状态”，允许研究员后续在工作台界面补齐。
3. **幂等同步**：
   - 提供 `POST /api/v1/previews/{preview_id}/sync-worksheets` 接口；重复执行建表动作具有幂等性，不重复生成样品或重复建档。

### 2.3 单元格清空、删除与租约控制
1. **单元格清空（作废）**：
   - 在前端工作表选中已采用单元格执行清空/Delete 保存时：系统将该单元格当前采用版本置为无效（作废），取消采用状态，并留痕记录作废人、时间及默认原因；单元格恢复为可重新填写状态，历史版本入口保留完整的作废审计记录。
   - **Excel 回传保护**：上传 Excel 的空白格默认代表“未填/未改”，不等于删除命令，严禁静默批量清空已有历史事实。
2. **检项行与研究表/样品移除**：
   - 删除检项行前必须通过接口展示受影响的结果、研究及关联引用；确认后作废该行关联的有效结果，并从当前应检矩阵中移除。
   - 删除研究表或样品执行软删除（记录 `deleted_at`），级联处理其所属关联，历史原件与已生成报告快照保持不可破坏。
3. **并发与租约控制**：
   - 采用 90 秒租约机制；同一操作员重新进入同一工作表支持自动接管租约；旧标签保存时若遇到租约过期，需重新获取并校验数据版本（Revision），保留用户已输入内容，禁止静默覆盖他人或后置提交。

### 2.4 COA 放行与 0M 快照
1. **独立快照复制**：
   - 提供 `POST /api/v1/worksheets/{sheet_id}/copy-coa-to-0m`。研究员可挑选指定样品、检项、方法和单位对应的确切 COA 放行版本，预览后生成正式稳定性 0M 结果。
   - 放行日期与稳定性开始日期不再要求强制处于 1 个月内，但保留来源比对。
   - 复制生成的 0M 结果作为独立事实维护；后续 COA 数据更新或修改，绝不会静默篡改已快照固化的 0M 数据。
2. **冲突策略**：
   - 目标格为空时按首次结果写入；同值自动跳过；已有不同数值时提供“更正”、“复测”或“保留原值”三种决策，严禁无感知覆盖。

### 2.5 质量标准、判定与受控交付
1. **标准适用性与上下限计算**：
   - 支持多版本质量标准登记，每个项目按材料范围（DS/DP）显式绑定当前有效标准版本。
   - 后端统一解析数值范围（包括开闭区间 `[a, b]`、`(a, b]`、`<`、`≤`、`>`、`≥`），前端根据判定结果展示红字与浅红背景超限提示；定性或不明确判定显示“待判断”，绝不盲目判为合格。导出的正式 Excel 保持原貌，不添加非受控的超限染色。
2. **常熟受控版式交付**：
   - 实现通用的受控汇总版式（不与特定项目号耦合）。
   - 按材料类型与放置条件分 Sheet 呈现，相同条件下的多个批次纵向堆叠排布，批次间空两行。
   - 每个批次块包含完整表头、双语检项名称、标准限度、时间点、计划日期及签署文字状态（如“已签”、“已签报告”）。
   - 区分“数据回传模板”与“受控交付报告”，防止误将交付文件作为回填模板导入。
