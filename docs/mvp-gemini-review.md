# 稳研工作台复审提示词

请作为产品经理和技术负责人审查稳研工作台本轮修改。先阅读 `mvp-business-workflow.md`、`mvp-data-lineage.md`、`mvp-real-file-acceptance.md`，再对照真实代码、接口契约、浏览器证据和隔离库。仅在独立 `--home` 中运行。生产数据及原件由用户本地维护。

逐条验证项目、样品、方案、标准、研究计划、结果版本、放行、趋势及导出之间的身份与版本是否一致。优先检查下列问题。

1. 人工核对保存后，是否能在同一页面完成预检、正式入库、刷新和 Excel 反读。对批注、辅助区域、删除线、双语和同格多值分别找证据。区分原件的真实含义和隔离验收的模拟解释。
2. 历史确认入库后，是否只映射已采用结果、避免重复建档，准确保留时间点、计划日期、签署状态和标准原文。缺信息时，检查研究员能否在提示后完成补齐。
3. 检查 COA 快照来源、旧动态引用转换、模板旧基线、分批回传及作废历史。检查影响预览、权限、幂等、revision、并发和回滚。
4. 核对两个真实批次在受控工作表的堆叠范围、标准、日期、备注及采用值。区分版式对照、结果反读和仅下载三种证据。
5. 查验迁移、隔离启动、服务重启、恢复和来源完整性。不要将全量自动化通过当作每份真实原件均通过。

按 P0/P1/P2 报告差距。每条写明用户触发路径、预期与实际、证据级别、可复现操作、代码位置、修复建议及回归门槛。对于拦截成功的情形，补查明确人工判断后是否能顺利入库，直至下载结果与库中采用值一致。待复核的业务含义保留证据和问题，勿用未经证实的选择覆盖原始记录。
