## 验证命令与恢复

最近一次全量后端回归运行 `.venv\Scripts\python.exe -m pytest -q`，455 项通过。前端运行 `npm run --prefix frontend/workbench typecheck` 与 `npm run --prefix frontend/workbench build`。契约使用 `scripts/generate_contracts.py` 生成并比对 OpenAPI。各项验证的范围和日期应以运行日志为准。

真实文件验收使用 `start.py --home <isolated-run>/home --port <isolated-port> --no-browser`。每轮保留原件 SHA256、操作结果及下载反读。启动前检查本轮端口与数据目录，避免浏览器连接到旧实例。迁移与退回操作见 [数据关系与回退路径](mvp-data-lineage.md)。正式上线还需按 [差距表](mvp-delivery-gaps.md) 完成后续验收。
